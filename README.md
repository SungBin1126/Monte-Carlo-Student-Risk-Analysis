# 몬테카를로 시뮬레이션을 활용한 학생 과락 리스크 분석

## 프로젝트 개요
- **주제:** 전통적인 다중회귀분석(OLS)이 가진 '단일 평균 예측의 한계'를 극복하고, 학생들의 학업 성취도에 내재된 변동성과 과락 리스크를 정량적으로 분석
- **분석 데이터:** 포르투갈 고등학교 수학 성취도 데이터셋 (UCI Student Performance Dataset) / 유효 표본 357명
- **사용 툴:** Python (`Pandas`, `NumPy`, `Matplotlib`), Google Colab

---

### 주요 분석 내용 및 방법론
1. **OLS 정규방정식 수동 구현**
   - 라이브러리에 의존하지 않고 회귀 계수($\beta = (X^T X)^{-1} X^T y$)를 직접 행렬 연산으로 구현하여 고위험군 시나리오 단일 예측치(10.29점) 도출
2. **솔레스키 분해(Cholesky Decomposition) 및 난수 생성**
   - 변수 간 상관관계(공분산)를 유지한 채 10,000명의 가상 학생 표본을 생성하기 위해 솔레스키 분해 행렬 연산을 수작업으로 구현
3. **몬테카를로 시뮬레이션 및 과락 확률 산출**
   - 시험 당일의 불확실성(오차 표준편차 1.42점)을 노이즈로 주입하여 10,000회 반복 실험을 수행한 결과, 단순 평균이 포착하지 못한 **24.14%의 숨겨진 잠재적 과락 리스크**를 정량적으로 규명
4. **시각화 및 대수의 법칙 검증**
   - 성적 분포 히스토그램을 통한 꼬리 위험 시각화 및 시행 횟수에 따른 확률 수렴 그래프 구현
